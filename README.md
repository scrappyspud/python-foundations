# Python Foundations

Hands-on Python exercises covering file handling, OOP, error handling and REST API integration, built while preparing for AI engineering work

## What's inside
| File | What it does | Concepts |
|---|---|---|
| top_players.py | Produces a json of top3 players based on runs scored based on an input json of players  | File handling, JSON, lambda, iterators|
| bank_account.py | Class Bank account with methods to withdraw and deposit | Classes, Exception Handling |
| github_profile.py | Uses Github API to retireve user information and display top 3 repos with most number of stars | API request and response handling |

## Setup
How someone would install and run it (venv, requirements.txt, command to run).
Create a virtual environment by running "python -m venv .venv" and activate it by ".venv\Scripts\activate".
Run "pip install -r requirements.txt" in the root of the project to install all dependencies.
Finally run the desired .py file by "python <file_name>.py"
